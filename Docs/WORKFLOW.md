# 工作与交接规范

更新时间：2026-07-21

## 每次任务的完成标准

代码修改、验证和文档同步全部完成后，任务才视为完成。每次任务结束前必须检查以下三类记录：

1. `ARCHITECTURE.md` 或 `Docs/`：更新受本次变更影响的架构、接口或使用说明；无相关变化时可不修改，但需在交接记录中注明。
2. `task_memory.md`：在文件末尾追加本次任务记录。
3. `TODO.md`：将已完成项移动到“已完成”，并补充明确的后续事项。

## 记录要求

- 时间使用 `YYYY-MM-DD HH:mm`，默认时区为 Asia/Hong_Kong。
- 记录任务目标、实际变更、验证结果、未完成事项和关键决策。
- 暂不记录操作者姓名。
- 不记录密码、令牌、私钥或其他敏感信息。
- `task_memory.md` 使用二级标题分隔任务，按完成时间顺序追加。

## 推荐流程

```text
确认需求 → 检查 TODO/交接记录 → 实现 → 验证
       → 更新架构/Docs → 写 task_memory.md → 更新 TODO → 完成
```
